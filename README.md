# English Class — Grade 1 & Grade 2

This is a GitHub Pages classroom website.

## Upload
Upload the contents of this package to the repository root. Keep the `css`, `js`, and `assets` folders.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

The homepage and Activity Area use the supplied 1920×1080 reference artwork:
- `assets/images/homepage.png`
- `assets/images/activitypage.png`

All navigation uses relative paths so it works from GitHub Pages.


## Reference artwork
The homepage and Activity Area use the supplied reference artwork directly. The Activity Area image contains the visible Grade 1/Grade 2 buttons; transparent accessible hotspots make those buttons clickable without covering the artwork.
