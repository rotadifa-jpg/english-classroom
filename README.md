# English Class — Jungle Learning Website

A GitHub Pages-ready Grade 1 & Grade 2 English classroom website.

## Upload to GitHub
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Open the GitHub Pages URL.

## Notes
- The site uses browser `localStorage` for music preference, saved songs, saved class links, and spinner/color settings.
- Speaker audio only plays after the speaker button is clicked.
- Background music is intentionally off until the visitor turns it on, because browsers commonly block autoplay.
- External links open in a new tab.
- Replace the files in `assets/` with your own original artwork/audio later if you want the visuals to match your supplied reference artwork exactly.
